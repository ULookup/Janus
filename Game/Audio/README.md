# Demo audio

Card.wav and Background.wav are original synthesized PCM16 mono, 24 kHz assets.
Recreate them with `python tools/generate_demo_audio.py` from the repository root.
No recordings, downloaded music, or third-party audio assets are used.

Card.wav is a 180 ms ascending tone with an envelope. Background.wav is a quiet
four-second eight-note loop. AudioSource volume controls the final mix separately.
