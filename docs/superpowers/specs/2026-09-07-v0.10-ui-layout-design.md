# v0.10 / 10-04a：UI 布局、图片与共享 Reparent

日期：2026-09-07。依赖 10-03 `RuntimeExecution`；实现位于当前开发分支，集成状态以[验收记录](../../verification/2026-09-07-v0.10-ui-layout.md)为准。范围源于[下一阶段路线](../plans/2026-09-07-next-stage-runtime-ui-roadmap.md)。

## 范围与所有权

Engine/UI 提供 Canvas、UIRect、Panel、Image 的作者态组件及无设备依赖的布局计算。Scene 保存/加载、克隆、Inspector、属性 Command、MCP schema 都使用宿主持有的 ReflectionRegistry。没有全局注册表、第二套 UI 树或 UI 专属存储格式，也没有新增第三方依赖。

首版仅支持一个位于 Scene 根级的屏幕空间 Canvas；多个或嵌套 Canvas 在布局阶段明确失败。没有 Canvas 的旧 Scene 保持原有渲染行为。允许作者逐步添加组件：Canvas 外的 UI 暂不绘制；非 Canvas 实体上的 Panel/Image 需要同实体 UIRect。没有 UIRect 的中间分组继承父矩形。Canvas 自身的矩形固定为整个逻辑屏幕，Canvas 上附加的 UIRect 几何不参与计算。

Canvas.enabled=false 隐藏整棵 UI；UIRect.enabled=false 隐藏该子树；Panel/Image.enabled 只控制本图元。空 Image 资产引用不绘制，已指定但无法解析的纹理返回带 UUID 的错误。颜色和几何通过反射 setter 验证，锚点、轴心限定在 [0,1]，锚点有序，布局拒绝非有限值及负的最终尺寸。size 可以为负，用于拉伸布局的边距。

## 布局与顺序

坐标原点在左上，X 向右、Y 向下。宿主传入项目 width/height 作为逻辑分辨率；Renderer 使用实际 viewport 绘制，不把物理像素写回作者态布局。UI 不继承世界 Transform 的平移、旋转或缩放。

设父矩形起点 P、尺寸 S，则：

```text
resolvedSize = S * (anchorMax - anchorMin) + size
resolvedMin  = P + S * anchorMin + offset - pivot * size
resolvedMax  = resolvedMin + resolvedSize
```

固定锚点时 size 就是宽高，pivot 决定锚定点位于自身的位置；拉伸时，pivot 同时插值锚点区间，所以最终公式中的扣减项是 pivot * size。支持零面积矩形但不生成图元。根 Canvas 默认裁剪到屏幕；UIRect.clipChildren 将子树进一步裁剪到该矩形。

UI 使用 Hierarchy 的子节点链表做前序遍历，父节点先绘制；同实体 Panel 在 Image 之前。后绘制的兄弟/后代覆盖先绘制的图元。`UILayoutResult.items` 同时保存完整矩形和裁剪后可见矩形；`HitTest` 倒序遍历并采用左上含、右下不含的边界规则。命中是几何候选查询，不表示已有 Button、事件分发、焦点或透明像素检测。

## 渲染与宿主接入

SceneRenderer 先解析世界 Sprite 和 UI 资源，成功后开始一帧。Renderer2D 先清屏并绘制原有世界队列，再切换到屏幕空间投影，绑定 shader 提交新矩阵，绘制 UI；一帧只清屏一次，统计累加两个阶段，结束或失败均释放当前离屏目标绑定。

世界 Sprite 原有按 layer/纹理排序不变。UI 队列只能合并相邻兼容图元，不能按纹理重排；Panel 使用 Renderer 拥有的惰性 1×1 白纹理，Renderer 销毁时释放。轴对齐裁剪在 CPU 上同时裁剪矩形和图片 UV，无公开 OpenGL/SDL 类型或新 backend 接口。

Application 与 Editor Game View 均传递项目逻辑分辨率。Game View 在 Stopped/Playing/Paused/Faulted 按既有 Scene 来源显示 UI；只有 Canvas、没有 Camera 的场景允许使用默认世界相机。Scene View 继续显示世界内容，UI 制作预览在 Game View；首版没有画布拖拽、Scene View UI picking 或单独的 UI 编辑器。

## Reparent 作者态契约

`ReparentEntityCommand(scene, entityUUID, parentUUID, siblingIndex)` 由 Engine 执行。nil parent 表示脱离到根；子级 index 从 0 开始，允许插入到末尾。根节点仍按持久 UUID 排序，因此根级 index 只接受 0。移动保留局部 Transform 和全部 UIRect 值，不做世界位置或屏幕位置补偿。

命令捕获原父 UUID 和兄弟位置。Execute、Undo、Redo 均通过现有 Scene 层级操作；目标缺失、越界、自身/后代环、Canvas 成为子级或跨 Canvas 移动在变更前拒绝。Undo 恢复原父级和兄弟位置；估算撤销内存、CommandEffect 和事务补偿沿用共享 CommandBus。

Editor Hierarchy 的 Parent 下拉框及 Earlier/Later 控件调用 EditorActions；MCP 增加 `scene.reparent_entity`，参数为 entity、parent（UUID 字符串或 null）、可选 siblingIndex 和 transaction。工具被显式分类为 SceneWrite，沿用 dispatcher、ProjectSession 的 Runtime/事务/恢复保护与 Activity；handler 不实现权限策略，不直接改 ECS。
