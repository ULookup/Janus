# v0.10 / 10-05a Button、事件与输入消费

## 边界

本包承接包含 `c71ad50` main、10-04a 布局及 10-04b Text 的本地工作树。实现点击计数菜单；不包含 10-05b 战斗规则、结构化游戏快照，也不宣称完成 v0.10。无新增依赖。

## 作者态与显示

`ButtonComponent` 包含 enabled、interactable，以及 normal/focused/pressed/disabled 四种颜色。固定调用同实体启用的 LuaScript 的 `OnClick(self)`，不保存函数表达式或跨实体引用；没有脚本或缺少 OnClick 是合法无操作，非函数或 Lua 异常返回 ScriptRuntimeFailed。

Button 复用 active ReflectionRegistry、Scene v1、Clone、共享 Command、Inspector 和 MCP 场景工具。hover/focus/capture 均由 RuntimeExecution 拥有的 UIInteraction 保存，不进入 Scene 持久化或 Undo。SceneRenderer 接收只读 UIInteractionState，按 Button → Panel → Image → Text → 子节点的稳定顺序绘制；Panel/Image 可覆盖 Button 背景颜色，需要反馈时使用 Button 自有颜色。UIRect.enabled 隐藏整个子树；Button.enabled 关闭该按钮自身的背景/交互，兄弟及独立装饰组件保持自身 enabled 语义。

## 输入合同

- InputState 保留最多 256 条按序事件和帧首指针；BeginFrame 清空边沿和记录。容量溢出取消本帧点击，并隔离 UI 控制直到释放，Core 不认识 UI 或游戏 action 名称。
- Viewport 映射同时映射帧首、移动事件和帧末位置。Editor 只接收 Game View 图像内输入，帧内起源于面板/留白的按压被过滤。Application 将窗口坐标映射到项目逻辑分辨率，保持窗口外按键与释放事件。
- 左键按下采用反向几何命中顺序。子标签解析到最近的 Button，且须位于该按钮可见矩形内；无关上层图元遮挡命中。interactable=false 的按钮阻挡下面的按钮，但不激活。
- 只有合法按下建立捕获；同目标有效释放才产生点击。拖出后再返回仍取消；隐藏、删除、失焦、离开逻辑屏幕、Pause/Stop 都取消。已消费的手势在取消后仍隔离到实际释放，防止按住回到 Game View 时泄漏给游戏。
- Up/Down 按布局绘制顺序遍历可见、启用、interactable 按钮，双向循环。无焦点时 Down 选择首个，Up 选择末个。Enter/Space 在焦点目标按下并释放时确认，repeat 不重复激活。点击设焦点；点空白取消焦点。
- 消费以本帧 key/button 为粒度，过滤 held、pressed、released、action 的帧首状态及对应事件记录；必要时保留前一游戏 held 的释放，避免游戏状态卡住。无 UI 消费时原生键与 action 查询保持兼容。Panel/Image/Text 本身不建立输入捕获。
- Start/Resume 对当前输入版本进行 Prime，避免重放启动/暂停期间已发生的短按；后续新帧正常接收输入。MCP Step 仍是 1/60、中性输入、不重载、不派发 UI。

## 共享执行顺序

RuntimeExecution 验证运行状态/时间 → 按当前布局收集 UUID 点击并生成游戏输入 → 可选脚本热重载 → 同实体受保护 OnClick → Lua OnUpdate。派发前重新校验实体/组件和脚本实例。渲染阶段重新布局，因此回调或 Update 的文字修改在同帧显示。Lua 错误通过既有 Result 传播；Editor Runtime 保留 Faulted 克隆及诊断，独立 Application 保持既有失败退出语义。所有步骤在宿主 owner thread 执行，MCP 不增设输入注入。
