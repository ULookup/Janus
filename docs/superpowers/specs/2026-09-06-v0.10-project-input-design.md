## 范围与契约

- 新增 Engine/Project 的版本化 `project.json`，Core Input 不依赖 JSON、Editor、Scene。配置包括名称、默认 Scene、registry/asset/script 路径、宽高、VSync、Target FPS、Action 多按键映射；所有路径保持 project-relative，并校验磁盘解析后的根目录边界。
- 没有 manifest 时维持 `Config/AssetRegistry.json` / `Scenes/Battle.scene`；不自动创建文件。显式 ProjectRuntimeConfig 路径覆盖 manifest，未指定则使用 manifest/default。非法或未知版本配置明确失败，不能默默回退。
- ProjectSettings 的 Engine 加载/校验/原子保存能力由 Editor 和 managed Application 复用。Editor 保留工具窗口尺寸，Game View 使用项目宽高比；独立游戏使用项目窗口尺寸。项目名和内容根的编辑不移动现有文件。DefaultScene/registry 变更下次打开项目生效，Input 下次 Play 生效，Game View 宽高比保存后更新；独立游戏窗口尺寸及 VSync/节流设置下次启动生效。AssetRoot/ScriptRoot 是内容目录声明，不重写现有 registry 的项目相对引用，也不在本切片新增导入器。
- VSync 控制 swap interval；Target FPS=0 不主动限帧，1–1000 为额外 CPU 帧率上限。两者同时开启时均生效，实际速度受较慢者约束；VSync 设置失败记录警告，仍执行帧率上限。用可注入的 sleep seam 测试节流，不用真实等待断言计时。
- Session 保存设置在 Runtime/事务/RecoveryRequired 时拒绝；写入失败不改变 session 配置。不改变 Scene dirty、Undo/history。配置文件保存不是 Scene Transaction；UI 明示生效时机。
- InputBindings 为有界、可验证的名字到 KeyCode 数组。Action down 是绑定键状态的 OR；pressed/released 是帧边界的聚合转换，并保留同一帧短按。另一键仍按住时不产生 release；帧内先释放再按回的已按住 Action 不产生新边界转换。未知 Action 的 C++ 查询返回空，Lua 明确报错；提供 has_action 便于旧脚本兼容。
- 后端无关指针移动/按钮与焦点丢失进入 InputState；失焦清除 held，保留当帧 release。Game View 坐标转换使用实际显示矩形与项目逻辑分辨率；工具面板/黑边/隐藏 Game View 不向 Gameplay 传输键鼠输入。Lua 指针坐标原点为左上，向右/下为正。
- ScriptEngine 显式持有绑定快照；managed Application 与 RuntimeSession 注入同一项目配置。暂停 Step 仍为中性输入和 1/60 秒，不能通过 Action 绕过暂停语义。完整共享 Runtime 调度收敛属于后续 10-03，本切片先以两个入口的集成测试验证输入一致性。
- Sandbox 提供 manifest 与 Action PlayerController；无 manifest 的历史脚本仍可使用原始 key API。Core/Engine 不定义游戏专属 Action 名称。
