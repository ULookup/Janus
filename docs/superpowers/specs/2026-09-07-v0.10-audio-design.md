## 范围与选型

交付 AudioClip、AudioSource、Play/Pause/Resume/Stop、Volume/Loop、Human/Agent 同源
作者态、Lua 控制、可观察运行态、战斗音效和背景循环。后续为 10-08 Physics、10-09
Prefab、10-10 综合验收；本包不代表 v0.10 发布。

架构文档说“miniaudio 等成熟库”，并未强制 miniaudio。本包复用已锁定的 SDL
release-3.4.14（zlib，现有 PRIVATE 链接），不增加依赖或更改项目许可证。
SDL_OpenAudioDeviceStream 的无 callback 模式接受应用提交 PCM；SDL 类型仅存在
Platform/SDL 实现内。参考 https://wiki.libsdl.org/SDL3/SDL_OpenAudioDeviceStream
和 https://wiki.libsdl.org/SDL3/SDL_ClearAudioStream 。

## 资产与作者态

注册类型 audio-clip，引用相对路径的 RIFF/WAVE PCM16 little-endian 文件。首版只接受
mono/stereo、8000–96000 Hz、最多 32 MiB 文件、120 秒，拒绝空数据、损坏 chunk、重复
fmt/data、非 PCM16、非法对齐/采样率。加载前限制读取量，解析前验证所有边界。
AssetCache 和播放实例共享不可变 AudioClip；Unload 不使正在播放的数据悬空。
每个新 Runtime Start 刷新配置 Clip；运行中无自动热重载，显式 Play 可重新加载。

AudioSource 持久化 clip/enabled/playOnStart/volume/loop，volume 为有限 [0,1]。
默认 disabled 允许共享 AddComponent 后设置引用再启用。沿 active ReflectionRegistry、
Scene v1、Clone、Command、Inspector 与 MCP 通用链，不增加直接 ECS 写入工具。

## 播放与输出

RuntimeExecution 拥有 AudioSystem 和设备；Lua 借用 AudioSystem，先清理 Lua，再清理
音频设备。状态以实体 UUID 为键；最多 64 个启用 Source，每个 Source 一个 voice。
Play 验证成功后替换/重启；Pause 保留游标，Resume 只恢复 source 自身暂停；Stop
回到游标 0。单次完成停在末尾，Loop 取余。Lua 改 volume/loop 不修改作者态。
删除/移除/禁用 Source 在下一次 Advance 清理。设备线程从不读取 Scene/Lua。

主线程在 Lua、Animation 后按模拟 dt 混合 48 kHz stereo float 数据，线性重采样并
饱和裁剪；一个 Advance 最多输出 100 ms，超长帧仍完整推进逻辑游标。SDL 队列上限
200 ms，积压时丢弃旧队列以避免无限延迟；此首版不承诺音乐级时钟同步或无缝卡顿恢复。
Pause/Faulted 清空队列并禁止输出；Paused Step 推进逻辑但静音；Resume 从当前游标
继续，逐 Source 暂停保持不变。启动暂停从第一次回调前生效；Start 不主动输出数据。
全局暂停/Source 停止会清理混合队列，其他 voice 保持逻辑游标，下次 Advance 继续。

设备在首次实际输出时惰性创建；无设备/提交失败记录有界错误并降级静音，项目和
Runtime 可继续，重启 Runtime 再尝试。C++ 只读状态和 Lua audio_state/audio_output
供 Diagnostics.publish_snapshot 发布必要播放状态，Agent 沿既有 RuntimeRead 读取。
缺失/损坏音频资产属于内容错误，明确失败并沿现有 Faulted 契约处理。
