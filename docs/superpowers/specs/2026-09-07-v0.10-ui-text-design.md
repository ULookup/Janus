## 交付边界

一条完整链路：Font 注册/解析 → Text 作者态 → Reflection/Command/Inspector/MCP → Scene v1 保存/克隆 → 共享 SceneRenderer → 两个宿主；Lua 通过运行 Scene 的实体更新文本。只支持单根屏幕空间 Canvas，沿用 10-04a 的逻辑分辨率、层级和裁剪契约。

没有新增第三方依赖。字体采用离线 RGBA 图集和 JSON 度量，纹理加载复用现有 pinned stb_image。示例的原始 5×7 位图字形直接写在项目 Python 生成器中，未复制系统或第三方字体，也未选择或添加项目 License。生成器只依赖 Python 标准库，正常 CMake 构建使用已提交的 PNG/JSON，不运行生成器。

## Font v1

AssetType 增加稳定名称 `font`，registry v1 不变。Font JSON 必须包含：

| 字段 | 契约 |
|---|---|
| version | 整数 1 |
| atlas | 已注册 Texture 的非空 UUID，不能是路径或另一个 Font |
| width / height | 图集像素尺寸，整数 1..8192，必须匹配实际图片头 |
| lineHeight / baseline | 字体原生行高 1..8192；从行顶至基线的距离 0..lineHeight |
| fallback | 必须存在且有可见面积、正 advance 的 Unicode 标量字形 |
| glyphs | 1..4096 项，codepoint 唯一且是 Unicode 标量 |
| 每个 glyph | codepoint、x/y/width/height 图集像素矩形；offsetX/Y 为相对笔位置/基线的偏移；advance 为水平笔位移 |

元数据最多 1 MiB；数值有限、advance 非负，字形矩形不得超出图集。空格可以零面积。解析失败返回 AssetDecodeFailed，未注册资源返回 AssetNotFound，类型错误返回 AssetTypeMismatch，IO 错误沿用现有 Result。

`AssetService::LoadFont` 返回服务拥有的只读 CPU 度量指针，直到 Font、依赖 atlas 或整个服务缓存被卸载。Font 不拥有 GPU 纹理；SceneRenderer 经原有 LoadTexture 解析 atlas。卸载 atlas 会使相关 Font 缓存失效，Clear/析构由现有纹理缓存恰好释放一次 GPU 资源。首版无文件监视或自动字体热重载，源文件改变需显式 Unload/Clear 或重新打开项目。

## Text 作者态与排版

Text 包含 `font`（font 约束的 AssetReference）、`content`、`fontSize`、`color`、`alignment`、`enabled`。默认空内容、24 逻辑像素行高、白色、left 对齐。允许先添加空字体引用再制作；可见的非空文本缺字体时明确报错，不静默消失。禁用或空内容不加载字体。

content 最多 4096 UTF-8 字节。拒绝过长编码、孤立 continuation、截断、surrogate、越界标量、NUL 和 CR/LF 以外的控制字符。CR、LF、CRLF 均是一次换行。合法但未收录的标量各显示一个 fallback；不按 UTF-8 字节拆成多个占位符。

fontSize 范围 (0,1024]，表示目标逻辑行高；缩放因子为 fontSize / Font.lineHeight。每行按 advance 求宽，left/center/right 独立对齐，偏移相对 UIRect。字形以 baseline + offsetY 定位。所有文字裁到自身 UIRect 和继承的父级可见区域，并同步调整 UV。首版只有显式换行，无自动折行、kerning、整形、双向布局、富文本或全中文字体承诺。

同一实体的绘制顺序为 Panel → Image → Text，然后子实体；一个 Text 的字形保持字符串顺序。UI 的反向几何命中继续基于共享布局项，文字按可见矩形命中，不按字形 alpha；10-05 才分发 Button 事件。

Text 使用 active ReflectionRegistry 的标准 Scene binding，已有属性命令、事务、Runtime/recovery guards、Scene v1 persistence/Clone 与 MCP schema 自然复用。Asset Browser 支持 Font 筛选和 Assign to Text，调用同一 EditorActions::SetProperty。Inspector 内容字段使用多行输入，字符串属性缓冲支持 4096 字节并按现有失焦提交逻辑调用 EditorActions；运行时保持只读。

## Lua 与资产发现

`self.entity:get_text()` 返回当前实体的 Text.content；`set_text(string)` 验证后原子替换。缺组件、失效实体、错误参数或非法内容沿用 Lua binding error；不会自动添加组件。只修改 ScriptEngine 所绑定的 Runtime Scene，两个宿主继续使用同一 RuntimeExecution，不添加第二套更新阶段。

`AssetRegistry::Search(name, type, offset, limit)` 是只读元数据查询，不触碰文件或加载缓存。name 是规范化项目相对路径的大小写敏感子串（含文件名），最多 256 字节；type 可省略，limit 默认 50、范围 1..100。按路径字典序，offset 分页，返回 assets 和 total；超过末尾得到空页。按最坏 JSON 转义估计的返回预算为 64 KiB，超限明确报错，可缩小 limit，不能静默遗漏条目。

MCP `assets.search` 暴露同一查询，返回 handle/type/path、total/offset/limit；拒绝未知字段、transaction 字段、未知类型及非法范围。offset 0..2147483647。标记 readOnlyHint，显式分类 ProjectRead，经已有主线程 dispatcher 和权限检查执行；Runtime/事务期间可查询，不改 dirty/history，不新增特权或直接 ECS 写路径。
