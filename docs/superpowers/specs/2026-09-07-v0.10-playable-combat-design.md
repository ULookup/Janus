## 游戏切片

`Game/` 为独立磁盘项目，可由 JanusSandbox 或 JanusEditor --project 启动。
只复用现有 Canvas/Text/Button/字体和共享 RuntimeExecution，不增加游戏 C++ 组件。
Game Lua 拥有菜单、选牌、出牌、胜利、失败和重开。敌方 HP=12，玩家 HP=6；
攻击造成 4 点伤害，未击败敌人时受到 2 点反击；等待造成 0 点伤害并受到反击。
每回合必须选牌再出牌，三次攻击胜利，三次等待失败。重开恢复菜单及全部数值。
鼠标和现有 Up/Down、Enter/Space 使用同一 OnClick 规则函数。
独立验证场景在 Update 调用同一个规则入口，可用中性 Step 验证，不注入 MCP 输入。

## 公共能力

新增 `ScriptSnapshot`：一个 VM/session 内最后显式发布的平坦标量映射。
Lua `Diagnostics.publish_snapshot(table)` 原子替换整份数据；仅接受 bool、有限 number、
有界 UTF-8 string，键为 ASCII 标识符。最多 32 字段、键 64 bytes、字符串 256 bytes、
合计 8192 bytes；拒绝嵌套表、函数、userdata、非法键、非有限数字，拒绝时保留上一份。
读取不执行 Lua、不访问任意脚本 table。字段由 Game 定义，Engine 不认识 HP/Card。
数据由 ScriptEngine 拥有，RuntimeExecution 赋运行 UUID 和发布帧索引；Start 帧为 0，
Update 发布标记尝试帧，失败时结合 RuntimeStatus.partialUpdate/failedFrameIndex 解释。
Stop/启动失败清空；新运行使用新 UUID；未发布返回 unavailable。

Application 和 RuntimeSession 暴露相同只读快照；MCP 注册
`engine://runtime/snapshot`，经既有 dispatcher 与 RuntimeRead 白名单读取缓存。
可带 `runtimeId` 和 `field` 查询；旧 ID、未知字段、非法参数明确错误；停止/未发布返回
available=false；指定 ID 必须匹配活动运行，指定 field 必须存在，否则报错。
Faulted 保留最后成功发布值和状态。快照是单槽最后发布值，热重载不主动清除；
新脚本发布时替换，Stop 清除。字符串沿用 Text 的 UTF-8 校验及仅 CR/LF 控制字符约束。
快照不序列化、不进入 Scene Undo/dirty，不改变 neutral Step、热重载或宿主生命周期。
