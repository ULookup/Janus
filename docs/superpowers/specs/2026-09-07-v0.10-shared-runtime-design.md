## 范围

在 Engine/Runtime 新增具体 `RuntimeExecution`，由 managed Application 和 RuntimeSession 复用。只收敛已有 ScriptEngine 生命周期和帧执行阶段；没有动态 Scheduler、空系统接口或新依赖。UI/动画/音频/物理不属于本包。

## 所有权与接口

- `Create(Scene&, AssetService&, initialInput, bindings)` 创建执行对象与 ScriptEngine；`Start()` 运行 OnCreate。分离两步以保留 Application 启动失败时的 client.OnShutdown 清理顺序。
- 对象拥有稳定地址的 InputState 和 ScriptEngine。ScriptEngine 持有绑定快照；外部 Scene/AssetService 必须存活到执行对象销毁后。对象不可复制或移动。
- `Advance(dt, input, ScriptReloadPolicy)` 先验证有限 dt 和运行状态，再复制本帧输入，按策略检查热重载，然后更新脚本一次。任一步失败立即返回 Error；脚本阶段的原 Error 不改写。不负责 Faulted 状态、帧计数、Scene Clone、渲染或退出。未启动时拒绝 Advance 必须保留 Create 时的输入快照。
- `Stop()` 复用 ScriptEngine 的幂等清理；析构兜底停止，确保 OnDestroy 在 Scene/资源仍有效时执行。启动失败与 OnDestroy 失败不得留下存活脚本实例或重复调用销毁回调。
- `InstanceCount()`/`IsRunning()` 只读查询执行状态。

## 宿主契约

- Application 保留自身 Scene 所有权和所有客户端回调时机，client.OnUpdate 后 Advance，随后渲染。磁盘项目错误仍返回失败并退出；非磁盘 managed 模式仍沿既有 RequestExit 行为。错误码和脚本错误正文原样返回；日志前缀可统一为 Runtime advance failure。
- Application 清理保持 client.OnShutdown → 执行对象 Stop/销毁 → Scene → AssetService → Renderer/图形上下文。
- RuntimeSession 保留 Clone、Play/Pause/Resume/Step/Stop、RuntimeStatus 与 fault retention；启动前刷新启用脚本的 AssetCache 策略保持在 Session，因为这是每次 Play 的宿主策略。
- Playing 传入源输入并检查 reload；Paused Step 使用临时中性输入，固定 1/60 秒，显式 Skip reload。Paused/Faulted 普通 Update 不推进；非法 dt 不改变状态。SourceInput 仍按既有约定借用，执行对象只同步复制。
- Scene/Reflection/Command/MCP 既有数据与权限契约不变；对象不依赖 Editor、MCP、ImGui、SDL 或 JSON。
