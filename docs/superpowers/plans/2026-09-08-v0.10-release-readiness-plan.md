## 4. 完整制作任务

最终 F2 使用候选 ZIP 的可写示例副本，连续执行：

1. 无参数启动欢迎页，打开示例副本，找到 Hero，切布局并重新启动确认恢复。
2. 新建项目内 Scene；创建 Camera、Sprite，赋 Texture 和 Lua，复制对象并移动，命名保存。
3. 给已有 Animator、Image 赋正确类型资源，故意拖错类型；确认原值不变，Undo/Redo 后保存重开。
4. 用可读名称导出 Prefab，找到并实例化，Undo/Redo 保持 UUID/子树；原实例不随源模板联动。
5. 运行综合示例，完成胜利、重开、失败、暂停/单步/继续/停止；观察日志、CPU 和 snapshot。
6. 编辑字段/设置草稿/Scene 后分别 X、Alt+F4、菜单退出；覆盖保存、放弃、取消和注入保存失败。
7. 新建/打开/另存/切项目含错误路径和坏文件；失败后旧场景可继续保存和操作。
8. MCP modern/legacy 完成读→修改→事务→Human Undo→保存→运行→观察；切场景/项目后旧请求明确失败，重新查询后可继续。

这些任务同时给首次试用者执行，保留原 UX 的时间目标和 4/5 独立完成目标。
完整任务通过不代表任意资产导入、存档或 v0.11 游戏完成；发布说明明确支持的已有项目/资源准备流程。
