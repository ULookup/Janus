# Janus v0.1 Engine Foundation Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 Janus v0.1 Engine Foundation，使 Sandbox 只通过 Engine 公共 API 获得 Application 生命周期、帧时间、窗口事件、键盘输入、文件 IO 和 OpenGL 4.5 Core Context。

**Architecture:** Core 提供不依赖 SDL 的 Time、Event、Input 和 FileSystem；Platform/SDL 将原生窗口、键盘事件和 OpenGL Context 翻译到 Janus API；Application 统一拥有并按确定顺序驱动这些能力。Sandbox 只实现 `ApplicationClient`，不再初始化 SDL、持有 Window 或手写主循环。

**Tech Stack:** C++20、CMake 3.24+、Ninja、MSVC、SDL 3.4.14、spdlog 1.15.3、Catch2 3.15.3、OpenGL 4.5 Core Profile。

**Spec:** `docs/superpowers/specs/2026-09-01-v0.1-engine-foundation-completion-design.md`

## Global Constraints

- v0.1 仅实现 Engine Foundation；不得加入 Renderer、ECS、Scene、Asset、Serialization、Lua、Editor 或 MCP。
- 不引入新的第三方依赖；OpenGL 函数加载和任何绘制命令留到 v0.2。
- Core Time/Event/Input/FileSystem 只能依赖 C++ 标准库，不得依赖 SDL 或 Renderer。
- Engine 公共 API 不得暴露 `SDL_Event`、`SDL_Scancode`、`SDL_Window`、`SDL_GLContext`、`GLuint`、`GLenum` 或 `gl*`。
- OpenGL 上下文固定请求 4.5 Core Profile；默认请求 VSync，设置失败记录 warning 后继续。
- Application 将单帧时间裁剪到最多 250 毫秒。
- 自动测试不得要求真实窗口、显示器或 GPU。
- Write concise comments for critical intent and invariants—especially ownership/lifetime, cleanup order, backend translation, and non-obvious algorithms. Explain why the constraint exists; do not restate what the code already says.
- 行为变更严格先写失败测试，再实现最小代码；每个任务只提交任务列出的文件。
- CMake 中 `.cpp` 和 backend 私有头为 `PRIVATE` source，只有有意公开的 API 头为 `PUBLIC` source。

- [ ] **Step 3: Implement TimeStep**

Create `TimeStep.h` with this complete public contract:

~~~cpp
#pragma once

#include "Core/Types.h"

#include <algorithm>

namespace Janus
{

class TimeStep final
{
public:
    constexpr TimeStep() noexcept = default;

    [[nodiscard]]
    static constexpr TimeStep FromSeconds(f64 seconds) noexcept
    {
        return TimeStep(seconds);
    }

    [[nodiscard]]
    static constexpr TimeStep FromMilliseconds(f64 milliseconds) noexcept
    {
        return TimeStep(milliseconds / 1000.0);
    }

    [[nodiscard]]
    constexpr f64 GetSeconds() const noexcept
    {
        return m_Seconds;
    }

    [[nodiscard]]
    constexpr f64 GetMilliseconds() const noexcept
    {
        return m_Seconds * 1000.0;
    }

    [[nodiscard]]
    constexpr TimeStep ClampedTo(TimeStep maximum) const noexcept
    {
        return TimeStep(std::min(m_Seconds, maximum.m_Seconds));
    }

private:
    explicit constexpr TimeStep(f64 seconds) noexcept
        : m_Seconds(std::max(seconds, 0.0))
    {
    }

    f64 m_Seconds = 0.0;
};

} // namespace Janus
~~~

- [ ] **Step 4: Implement FrameClock**

Use the following interface and make the no-argument overload delegate to `Clock::now()`:

~~~cpp
// FrameClock.h
#pragma once

#include "Core/Time/TimeStep.h"

#include <chrono>
#include <optional>

namespace Janus
{

class FrameClock final
{
public:
    using Clock = std::chrono::steady_clock;
    using TimePoint = Clock::time_point;

    [[nodiscard]] TimeStep Tick() noexcept;
    [[nodiscard]] TimeStep Tick(TimePoint now) noexcept;

private:
    std::optional<TimePoint> m_Previous;
};

} // namespace Janus
~~~

~~~cpp
// FrameClock.cpp
TimeStep FrameClock::Tick() noexcept
{
    return Tick(Clock::now());
}

TimeStep FrameClock::Tick(TimePoint now) noexcept
{
    if (!m_Previous)
    {
        m_Previous = now;
        return TimeStep{};
    }

    const auto elapsed = std::chrono::duration<f64>(now - *m_Previous).count();
    m_Previous = now;
    return TimeStep::FromSeconds(elapsed);
}
~~~

- [ ] **Step 4: Implement the non-global InputState**

Use three `std::bitset<static_cast<usize>(KeyCode::Count)>` values for held, pressed, and released state. `BeginFrame()` resets only pressed and released. `Apply` ignores window events; a repeated key-down sets held but never sets pressed:

~~~cpp
void InputState::Apply(const Event& event) noexcept
{
    if (const auto* pressed = std::get_if<KeyPressedEvent>(&event))
    {
        const auto index = static_cast<usize>(pressed->key);
        if (!pressed->repeat && !m_Down.test(index))
        {
            m_Pressed.set(index);
        }
        m_Down.set(index);
        return;
    }

    if (const auto* released = std::get_if<KeyReleasedEvent>(&event))
    {
        const auto index = static_cast<usize>(released->key);
        m_Down.reset(index);
        m_Released.set(index);
    }
}
~~~

Expose only:

~~~cpp
void BeginFrame() noexcept;
void Apply(const Event& event) noexcept;
[[nodiscard]] bool IsKeyDown(KeyCode key) const noexcept;
[[nodiscard]] bool WasKeyPressed(KeyCode key) const noexcept;
[[nodiscard]] bool WasKeyReleased(KeyCode key) const noexcept;
~~~
