## 实现结果

- 默认 Game 是 `Scenes/Integrated.scene`：18 个作者态实体，菜单、卡牌按钮、
  两个展开的 Fighter Prefab 子树、世界动画、背景/出牌音效、刚体落地和受击反馈。
  游戏伤害仍由 Combat.lua 的同一入口结算；Physics 负责反馈，不改变卡牌规则。
- Fighter 模板可通过资产发现、共享 MCP/Editor 命令实例化。实例拥有独立 UUID、
  子节点、物理体和动画状态；不引入运行时生成或模板关联/覆盖。
- Arena.lua 组合游戏系统和快照。正常场景由按钮/Action Input 驱动；独立的
  IntegratedVerification 调用相同 Game 入口，480 个中性 Step 覆盖胜利、重开、失败。
- RuntimeExecution 借用宿主持有的 CpuProfiler：UI、Reload、Lua、Physics、Animation、
  Audio 分阶段计时，失败时作用域仍闭合。Physics 计时包含其事件的 Lua 回调。
  ProjectSession 的 recorder 生命周期先于 Runtime；Application 持有自己的 recorder。
- 修复原生验收发现的 Game View 缩放偏移：世界投影与 UI 使用相同逻辑尺寸，
  RenderTarget/设备 viewport 仍保持实际像素；Scene View 编辑相机保持原有语义。

## 原生验证

通过 computer-use 对真实 Windows 窗口操作，未用 FakeRenderDevice 替代这些观察：

- JanusSandbox：加载 18 个实体，显示字体、按钮、两个机器人和出牌动画；
  鼠标开始，鼠标与数字键混合出牌，三回合胜利；`0` 恢复菜单与满血；Escape 正常退出。
- JanusEditor：初次检查发现小 Game View 下世界/UI 比例不一致；修复后重新构建并打开，
  对齐正确且地面可见。Play 后角色落地；Game View 点击开始、`3`/`4` 三回合失败；
  Pause、Step 保持暂停/失败状态；Stop 后 Game View 恢复初始菜单、作者态角色位置。
- 原生 stdio：生产 Debug JanusEditor 使用 `--mcp-stdio`，modern/legacy 均完整通过
  相同的作者态任务与 480 Step，包含 OpenGL 渲染与真实主线程调度路径。
  原生 Editor 暂停时继续产生渲染帧，测试通过有界 `frameId` 历史查询寻找已完成 Step，
  不假设 latest 总是模拟帧，也不为读取诊断推进游戏。
- `JanusAudioDeviceSmoke.exe` 未设置 dummy 驱动：3 轮设备打开、每轮提交 48000 帧、
  清空与关闭通过。没有进行人工音质试听；不把 API 提交成功表述为主观听感结论。

原生 OpenGL 输出既有 `id=131218` shader state performance warning；未发现脚本、
内容或 Render 错误。该驱动警告不等同于 GPU 性能测量。

## CPU / Renderer 基线

环境：Windows 11 `10.0.26100`，Intel Core i9-14900HX（24 核/32 逻辑处理器），
MSVC 14.38、Debug，SDL 3.4.14，Audio dummy、FakeRenderDevice。
暖机 180 帧，测量 720 帧；固定 1/60 s，每 180 帧一轮三次攻击与重开。
最终场景 18 个实体、3 个物理体，最大 309 sprites、15 draw calls、15 texture binds。

| CPU 范围 | median ms | p95 ms |
| --- | ---: | ---: |
| 整段模拟与渲染提交 | 1.706 | 2.087 |
| Runtime.Update（父范围） | 0.734 | 0.970 |
| UI | 0.064 | 0.098 |
| Reload | 0.091 | 0.133 |
| Lua | 0.256 | 0.396 |
| Physics（含回调） | 0.207 | 0.281 |
| Animation | 0.043 | 0.057 |
| Audio | 0.049 | 0.080 |
| Render CPU 提交 | 0.946 | 1.211 |

整段最大 2.681 ms。60 Hz 整帧预算为 16.667 ms；该 Debug CPU 样本在预算内，
但不包含 GPU、Present、驱动等待、输入轮询或客户端更新，不能据此声称真实整帧满足预算。
父子范围不能相加。计时不设机器相关 CTest 硬阈值；后续在同硬件/同配置比较 p95 和
绘制统计，新增系统前重新测量。首次预览和并行原生 stdio 运行期间的采样不作为最终基线。

在 Visual Studio Developer PowerShell，从仓库根目录执行：

```powershell

./out/build/windows-msvc-debug-tests/Tests/JanusAudioDeviceSmoke.exe
python Tests/MCP/integrated_external_e2e.py --host out/build/windows-msvc-debug/Editor/JanusEditor.exe --project Game --era modern --native-editor
python Tests/MCP/integrated_external_e2e.py --host out/build/windows-msvc-debug/Editor/JanusEditor.exe --project Game --era legacy --native-editor
git diff --check
```

PkgConfig/LibUSB 未发现；EditorApplication.cpp 的 `getenv` C4996；此前测试重编译时
McpEditorHostTests.cpp 的 C4834。这些均不由本次修改引入。
