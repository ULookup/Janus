## 交付限制

固定两张可重复使用的卡牌、单个逻辑 Canvas、项目现有拉丁字形集；没有动画、音效、
物理、存档、多 Scene 流程或完整 Roguelike。快照是单槽最后发布值，不是持久化/历史；
热重载保留上次发布直到脚本重新发布。Game 控制器依赖 Scene 中最小脚本 UUID 的启动
顺序，按钮通过同实体 name 对应 Game 动作；这些名称是示例项目脚本合同。
