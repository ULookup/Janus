## 真实 Windows / OpenGL 检查

使用 `out/v010-ui-demo` 中的临时项目副本，将 defaultScene 设为 UIShowcase.scene；未覆盖原项目设置。通过 Computer Use 操作测试构建的真实原生窗口：

1. Sandbox 显示完整 Canvas、交错图片与 Panel 的遮挡、被父 Panel 边界裁掉的图片，以及右/底锚定元素。最大化后实际窗口从 1280×720 变为 2560×1494，布局重新覆盖目标；独立窗口当前按整个 viewport 缩放，不承诺保留宽高比黑边。
2. Editor Stopped Game View 显示相同布局，并在其现有 16:9 适配区域内呈现；Inspector 可见 Canvas/Panel/UIRect 的作者态字段。
3. 选中 FrontCard 点击 Earlier，卡片移至 BackCard 前面，画面中也变为被 BackCard 遮挡；点击 Undo 后层级和画面同时恢复。
4. Play/Pause/Step 保持 UI 显示和作者态写保护；Stop 按 Editor 既有行为返回 Scene 标签，切回 Game 标签后作者态 UI 正常。Step 未增加输入注入能力。
5. 保存临时场景成功，Unsaved 标记消失；逐字段对照保存文件，13 个实体的作者态数据与 Undo 前原始示例一致（浮点容差 1e-6）。Sandbox 和 Editor 均通过正常关闭流程退出，宿主进程退出码为 **0**。

## 本地试用

从仓库根目录执行以下 PowerShell，在临时副本中启用示例：

```powershell
$uiDemo = Join-Path $env:TEMP ("janus-ui-" + [guid]::NewGuid().ToString())
Copy-Item -LiteralPath .\SandboxProject -Destination $uiDemo -Recurse
$uiManifest = Join-Path $uiDemo 'project.json'
$uiConfig = Get-Content -LiteralPath $uiManifest -Raw | ConvertFrom-Json
$uiConfig.defaultScene = 'Scenes/UIShowcase.scene'
$uiConfig | ConvertTo-Json -Depth 8 | Set-Content -LiteralPath $uiManifest -Encoding utf8
& .\out\build\windows-msvc-debug\Sandbox\JanusSandbox.exe $uiDemo
& .\out\build\windows-msvc-debug\Editor\JanusEditor.exe --project $uiDemo
```

Editor 中选择 Game 标签预览，展开 Canvas → ClippedPanel，选中 FrontCard 使用 Earlier/Later，并通过 Undo/Redo 对照画面。
