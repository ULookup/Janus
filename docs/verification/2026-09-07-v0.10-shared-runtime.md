## 交付

| 内容 | 实现 |
|---|---|
| 共享执行对象 | Engine/Runtime/RuntimeExecution：Create/Start、owned InputState、bindings snapshot、可选 reload → Update、Stop/析构清理 |
| 独立入口 | Application 通过执行对象运行自身 Scene；不引入 Clone，客户端持有的 Scene 引用保持稳定 |
| Editor 入口 | RuntimeSession 继续管理隔离世界、状态机与 RuntimeStatus，通过同一个对象执行脚本 |
| 单步 | 1/60 秒、中性输入、ScriptReloadPolicy::Skip；暂停/故障的普通 Update 不推进 |
| 生命周期 | client.OnUpdate 先于模拟；client.OnShutdown 先于脚本 Stop；执行对象先于 Scene/AssetService 销毁 |
| 错误 | reload 失败不再执行 Update；Editor 留 Faulted 现场，磁盘 Application 返回失败并清理；错误码和脚本正文保留 |

未新增依赖、游戏专属类型、Scene 序列化字段或 MCP 工具。实现源 `.cpp` 为 CMake PRIVATE，RuntimeExecution.h 为意图明确的 Engine API。独立入口日志前缀由分别描述 Lua reload/update 改为 `Runtime advance failed`，原始 Lua 错误正文和 ErrorCode 保留。

## 先测试后实现

1. 增加 RuntimeExecution 测试与 CMake 注册；构建因 `Runtime/RuntimeExecution.h` 缺失而失败。证据：`out/v010-runtime-red-build.log`。
2. 增加同一磁盘 fixture 的 Application/Editor 对比测试，再实现共享对象和两个宿主迁移。
3. 首次新测试运行 7/8 通过，复现“未 Start 的 Advance 覆盖初始输入快照”；增加运行状态前置校验，确保拒绝操作无输入副作用。原始失败：`out/v010-runtime-narrow.log`；修复后 8/8、188 assertions 通过。
4. 补充 Application client shutdown 与 Lua OnDestroy 顺序/单次清理测试。最终新增 9 个 CTest 用例；相关回归为 25 个测试、361 assertions。

自动测试覆盖：

- 输入与 bindings 独立快照、单次 OnCreate/Update、未启动/重复启动/停止后操作；
- 热重载先于更新，Skip 保留旧源，非法脚本不执行旧 Update，时间戳变化通过显式 last_write_time 设置完成，无等待断言；
- 非有限时间步不重载、不推进；部分启动失败回收先前实例；OnDestroy 失败仍清空全部实例，重复 Stop/析构不重复销毁；
- 两个宿主运行同一 project.json/Scene/Lua，逐帧比较 Action 多键切换、repeat、指针与失焦输入、dt、Transform 和 Runtime frame/id；
- Application OnInitialize/OnUpdate/OnShutdown 持有同一 Scene，更新先于 Present，client shutdown 先于脚本销毁；
- 同一 Lua 更新失败在 Application 返回原 Error，在 Editor 保留 partial update 与 Faulted 世界，作者态 Scene 保持原值；
- Paused Step 不读取磁盘新脚本、无 Action/指针输入、保持 1/60 秒；Stop/重新 Play 刷新共享 AssetCache 中的脚本。

## 真实 Windows / OpenGL 验收

使用本次构建的 `out/build/windows-msvc-debug-tests/Sandbox/JanusSandbox.exe` 与 `Editor/JanusEditor.exe`，打开各自构建目录复制的 SandboxProject；没有编辑用户源项目。窗口操作通过 computer-use 的 @oai/sky 完成。

- Sandbox 启动后显示两个纹理 Sprite 的真实 OpenGL 画面；通过 Alt+F4 发起窗口关闭，进程随后退出。
- Editor 启动显示作者态 Scene；点击 Play 后 Game View 显示场景且状态为 Playing。
- 点击 Pause 后状态 Paused，点击 Step 后仍为 Paused；没有出现 Faulted。固定时间步与输入中性的精确值由自动测试验证。
- 点击 Stop 恢复 Stopped、Scene View 和作者态操作入口；Console 可见 Play Mode started / Play Mode stopped。可见 Console 中有既有 Profiler 开销门槛警告，本包未改其策略。
- Alt+F4 关闭 Editor 后，用进程查询确认这两个验收进程均已退出，结果在 `out/v010-runtime-live-close.log`。窗口工具启动的进程未可靠采集退出码，不宣称获取了 exit code 0。

独立窗口曾发送一次短 D 键，但截图未显示可靠位移差异，因此不将其计作本次真实输入移动验收；输入一致性由新的双宿主逐帧测试和 Stage A 历史验收支持。本次未重做完整 MCP 手工读回或性能 benchmark；外部协议和 MCP guards 由全量回归覆盖。
