## 边界

只有 Sprite 帧动画，无骨骼、状态机、动画编辑器、事件轨道或固定物理调度。
每个 Animator 仅允许一个同实体 SpriteRenderer 或 Image 目标；首次渲染通过已有 Texture
加载路径报告丢失/损坏 atlas。Playback 持有 Clip 值副本，运行中不自动热重载 Clip；
新 Runtime Start 刷新配置 Clip，显式 Play/Switch 可使用卸载后重新加载的资源。
Game 快照在 Lua Update 发布，反映该帧 Animation Advance 前的状态。
Audio、Physics、Prefab 与 v0.10 综合验收仍待完成。

完整本地日志位于忽略的 `out/animation-configure-*.log`、`out/animation-final-build-debug.log`、
`out/animation-final-build-tests.log`、`out/animation-final-narrow.log`、`out/animation-final-ctest.log`
和 `out/animation-*-native*.log`；不提交生成目录、二进制或日志。
