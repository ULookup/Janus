## 审查边界与修复

- Prefab 单根有界解析、UUID 重映射、显式 Reflection、原子注册发布与失败清理，
  以及共享命令的 Undo/Redo、事务和运行保护。
- Runtime 计时对象生命周期、失败作用域闭合、世界/UI 逻辑投影与旧 Scene View 兼容。
- Game 集成的脚本引用生命周期、确定性规则、物理反馈和 Human/Agent 操作链。

发现并修复：单独热重载 Combat.lua 会替换 `JanusCombat` 表，Arena 的闭包仍引用旧表，
后续快照失去 `hits` 等组合字段、按键动作也无法继续触发原先的物理反馈。
先添加回归测试，旧实现确实在 `fields.contains("hits")` 失败；
修复为复用同一 Runtime Lua VM 内的状态表，更新控制器与规则入口，再重置战斗。
Arena 绑定与角色引用保留，新 Runtime 仍从全新的 VM 开始，Engine API 未改变。

修复后测试验证：脚本文件真实改动并推进 timestamp 后自动重载；同一个 run UUID，
三个物理体不变，动作后 enemyHp=8、hits=2，Scene dirty 保持 false。
