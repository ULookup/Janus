## 自动验证

Visual Studio Developer PowerShell，MSVC 14.38 x64，使用仓库预设：

```powershell
cmake --preset windows-msvc-debug
cmake --build --preset windows-msvc-debug --parallel 2
cmake --preset windows-msvc-debug-tests
cmake --build --preset windows-msvc-debug-tests --parallel 2
$env:SDL_AUDIO_DRIVER = 'dummy'
./out/build/windows-msvc-debug-tests/Tests/JanusTests.exe '[audio],[combat]'
./out/build/windows-msvc-debug-tests/Tests/JanusTests.exe 'ProjectSession opens the disk-backed SandboxProject for authoring'
ctest --preset windows-msvc-debug-tests
git diff --check
```

两套 configure/build 成功。音频/战斗窄测试 **15 项、582 assertions 全通过**；
ProjectSession 定点复测 **1 项、10 assertions 全通过**。最终完整 CTest
**384/384、0 failed，16.77 秒**，包含 4 项外部进程 MCP 回归。diff --check 通过。
CTest 为 JanusTests 显式设置 SDL dummy driver；核心音频测试另外注入 fake sink，
不依赖 CI 的扬声器/GPU。实际设备 smoke 独立于 CTest。

新增测试先于实现添加，初次构建按预期因 AudioClipLoader.h 不存在而失败，记录在
out/audio-red-tests.log。首轮完整 CTest 有 1 项旧目录计数断言失败（11→12）；已更新
ProjectSession 注册数并增加 AudioSource 注册检查，定点和全量复测通过。

覆盖：RIFF 长度/chunk/padding/重复 fmt/data、PCM 格式/采样率/对齐、空文件、缺文件、
32 MiB 读取上限、120 秒时长、正负立体声样本、缓存共享、饱和混音、64-source 上限、
大 dt 与循环、单次末尾、暂停/恢复/停止、非法参数和失败 Play 原子性、资产卸载及
重启刷新、禁用/销毁、设备不可用/中途失败且不反复打开、场景保存/Clone/Undo/Redo、
Lua、Paused Step 静音、故障及失败 OnDestroy 清理。已有真实 managed Application 与
Editor ProjectSession 的战斗逐帧比较现在同时比较新增音频快照字段。

编译保留已有 EditorApplication getenv C4996、McpEditorHostTests C4834 警告；
本包音频代码无新增编译警告。SDL 配置的可选 PkgConfig/LibUSB 缺失不影响成功生成。

## 本机设备与生产 Editor

在未设置 SDL_AUDIO_DRIVER=dummy 的独立 shell 中执行：

```powershell
./out/build/windows-msvc-debug-tests/Tests/JanusAudioDeviceSmoke.exe
```

真实默认设备 3 轮 open → 每轮提交 48000 stereo frames → clear → close 均成功，
exit 0；无静音 fallback 可以使这个程序通过。

另启动真实 `JanusEditor --project <repo>/Game --mcp-stdio`，通过原生 modern MCP
依次执行 runtime.play(startPaused=true)、step、play（恢复）、pause、step、stop、
再次 play/stop。启动暂停/单步未打开设备；恢复后读取到：

```json
{"audioAvailable":true,"audioError":"","cardAudioStatus":"Stopped",
 "musicAudioStatus":"Playing","musicAudioCursor":0.3042955666666666}
```

Pause 期间快照不变，Step 仍保持 Paused，Stop 清除发布，重开设备成功。stdio 输出
全部为协议 JSON，stderr 只有正常平台/窗口/项目初始化信息，无音频或 Lua 错误。
测试先显式停止 Runtime，再由本地进程夹具结束 Editor；不将其记为窗口人工关闭验收。
本轮没有重做鼠标/键盘和画面人工验收，相关行为由既有自动回归覆盖。

设备提交与实际 Editor 的播放状态已验证；**没有人工确认扬声器听感、延迟或音质**。
可运行 Game 或 device smoke 试听。本包不声称完成物理、Prefab 或 v0.10 综合设备验收。

混合队列后其他 voice 从逻辑位置继续。播放状态不代表扬声器的测量时间。
