## 本地试用与后续

从仓库根目录用 PowerShell 创建临时副本：

```powershell
$textDemo = Join-Path $env:TEMP ("janus-text-" + [guid]::NewGuid().ToString())
Copy-Item -LiteralPath .\SandboxProject -Destination $textDemo -Recurse
$manifest = Join-Path $textDemo 'project.json'
$settings = Get-Content -LiteralPath $manifest -Raw | ConvertFrom-Json
$settings.defaultScene = 'Scenes/TextShowcase.scene'
$settings | ConvertTo-Json -Depth 8 | Set-Content -LiteralPath $manifest -Encoding utf8
& .\out\build\windows-msvc-debug\Sandbox\JanusSandbox.exe $textDemo
& .\out\build\windows-msvc-debug\Editor\JanusEditor.exe --project $textDemo
```

Editor 选择 Game 标签，展开 Canvas 并选中 HealthLabel 编辑 Text。Asset Browser 选择 Font 类型，选中 JanusPixel.font.json 后使用 Assign to Text。

首版字体包含拉丁字母、数字、有限标点；不承诺全中文、复杂文字整形、kerning、自动折行、富文本或字体自动热重载。HP 循环只是显示示例，没有 Button 或战斗规则。下一包为 **10-05a Button/事件/输入消费**，随后才是 10-05b 单局玩法和游戏诊断；本包不代表整个 v0.10 完成或发布。
